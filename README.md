# 🎓 Student Performance Data Analysis System

## 📌 Project Overview

This project analyzes student performance data using Python and Pandas. It includes data cleaning, preprocessing, feature engineering, visualization, and report generation.

## 🚀 Features

- Data Loading
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Feature Engineering
- Grade Calculation
- Student Performance Analysis
- Attendance Analysis
- Gender-wise Analysis
- Data Visualization
- Correlation Heatmap
- Histogram
- Export Processed Report

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## ▶️ How to Run

1. Clone the repository
2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Open the notebook in Jupyter Notebook
4. Run all cells

## 📌 Key Insights

- Science has the highest average marks.
- Top-performing students scored above 90%.
- Attendance analysis identifies highly regular students.
- Gender-wise comparison highlights performance trends.
- Correlation analysis shows relationships between academic subjects and attendance.

This project demonstrates practical data analysis using Python and Pandas, including data cleaning, preprocessing, visualization, and report generation.
